# Geeft — identità grafica (v2 chiusa)

Generica. Compleanni, nascite, matrimoni, liste di famiglia. **Niente Natale.**

## Prodotto

Liste regalo in famiglia. La privacy è la sorpresa.

## Nome

**Geeft** — G maiuscola, resto minuscolo. Mai GEEFT tutto maiuscolo sul logo.

## Marca

Pacco regalo geometrico moderno: angoli arrotondati, nastro a croce, fiocco a due archi. Niente cartellino.

## Palette (chiusa)

| Token | Hex       | Ruolo            |
| ----- | --------- | ---------------- |
| Slate | `#5C6B7A` | pacco / primario |
| Peach | `#E8A87C` | nastro / accento |
| Mist  | `#EDE8E1` | superfici        |
| Ink   | `#1C1917` | testo, wordmark  |
| Paper | `#FAF7F2` | fondi            |

Clay (`#C45C26`) scartata.

## Tipografia

Wordmark sans geometrica, bold, tracking stretto. UI = stack del rebuild.

## Evitare

Alberi, stelle, calze, neve, rosso+verde, fiocco realistico, cartellino, copy natalizia.
