# Geeft brand assets

Identità grafica v2 in `IDENTITY.md`. Palette **Slate + Peach** in `PALETTE.md`. Mark: pacco regalo geometrico. Generica: niente Natale.

## File

- `logo.svg` / `logo.png` — pacco + wordmark
- `mark.svg` / `mark.png` — solo pacco
- `small.png` — 192×192, favicon/compatta
- `android.png` — 1024×1024, icona PWA/Android
- `android-source.svg` — sorgente dell’icona
- `palette.svg` / `palette.png` — swatch dei token
- `overview.html` — anteprima locale del pack

Il rebuild usa questi file per logo, favicon, manifest e icone PWA.
